Du bekommst eine Beschreibung einer Automation in normaler Sprache. Erzeuge einen gültigen n8n-Workflow als JSON.

Antworte NUR mit dem JSON, keine Erklärung davor oder danach, kein Markdown-Codeblock.

Format:
{
  "id": "<eindeutige-id>",
  "name": "<kurzer Name>",
  "nodes": [
    {"id": "<uuid>", "name": "<Name>", "type": "<Node-Typ>", "typeVersion": 1, "position": [x, y], "parameters": {...}}
  ],
  "connections": {
    "<Quellname>": {"main": [[{"node": "<Zielname>", "type": "main", "index": 0}]]}
  }
}
